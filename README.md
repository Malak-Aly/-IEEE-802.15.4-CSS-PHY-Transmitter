# -IEEE-802.15.4-CSS-PHY-Transmitter
The design, implementation , and verification of a synthesizable Verilog implementation of the CSS PHY transmitter chain described in the  IEEE Std 802.14.5 following the same design flow used in industry: floating-point reference model → fixed-point model → RTL (Verilog) design → simulation/verification → FPGA synthesis &amp; implementation .
## MATLAB Verification

The `matlab_verification_script` folder checks the RTL output against a MATLAB golden model.

**How it works**

The script `golden_script.m` runs the MATLAB reference code. It then compares the MATLAB results with the output files generated by the testbench. The results should be identical.

**Library and paths**

To run `golden_script.m`, we used the MATLAB library provided to us. We kept the same folder paths as in that library. If you move the files or change the paths, the script will not find what it needs.

**Files in this folder**

- `payload.txt`: the payload used by the testbench and the MATLAB code.
- `rtl_tx_real_output.txt`: the real part of the output generated by the testbench.
- `rtl_tx_imag_output.txt`: the imaginary part of the output generated by the testbench.

These files are in the same folder as the script on purpose. The script reads them from here.

**How to run**

1. Run the simulation in the `sim` folder to generate the output files.
2. Copy the new output files into `matlab_verification_script` if you changed the design.
3. Open `golden_script.m` in MATLAB and run it.
4. Check that the MATLAB results match the testbench output files.
