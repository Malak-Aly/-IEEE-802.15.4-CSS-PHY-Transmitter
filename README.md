# -IEEE-802.15.4-CSS-PHY-Transmitter
The design, implementation , and verification of a synthesizable Verilog implementation of the CSS PHY transmitter chain described in the  IEEE Std 802.14.5following the same design flow used in industry: floating-point reference model → fixed-point model → RTL (Verilog) design → simulation/verification → FPGA synthesis &amp; implementation .
